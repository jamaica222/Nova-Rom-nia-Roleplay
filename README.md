CAP.1TRAFFIC STOP
-Ce inseamna Traffic Stop?: Este atunci cand o persoana este trasa pe dreapta ca a fost surprinsa facand ilegalitati in trafic.
CAP.2 PIT STOP
Ce inseamna PIT-STOP?: Este expresia initiata la americani insemnand (Pursuit Intervention Technique ) insemnand “Tehnica de Interventie  in Urmarire” unde aceasta tehnica se foloseste pentru a incerca sa opreasca autovehiculul care incearca sa fuga de politie .
Tehnica este una de mare risc unde pot fi ranite persoane, de aceea trebuie facuta cu atentie in afara oraselor deoarece exista riscul ca un pieton sa fie ranit in urma efectuarii acestei manevre
 
CAP.3 FELONY STOP
Ce inseamna FELONY STOP?: Este tot o expresie Americana, se efectueaza atunci cand un politist are motive foarte serioase sa creada ca soferul sau pasagerul sunt suspecti de savarsirea unei crime grave sau ca suspectii pot fi inarmati sau foarte periculosi. aceasta manevra se mai folosesti cand pe numarul masinii exista un mandat de arestare .
